# next-word-prediction-lstm
## Project Overview

This project implements a Next Word Prediction model using a Long Short-Term Memory (LSTM) neural network trained on the Medium Articles Dataset. Given a sequence of words, the model predicts the most probable next word using deep learning techniques.

The project demonstrates the complete NLP workflow, including text preprocessing, tokenization, sequence generation, model training, and inference.

---

## Dataset

- **Dataset:** Medium Articles Dataset
- **Source:** https://www.kaggle.com/datasets/dorianlazar/medium-articles-dataset

---

## Features

- Text preprocessing and cleaning
- Tokenization using TensorFlow/Keras
- Vocabulary generation
- Input sequence creation
- LSTM-based language model
- Next word prediction
- Model evaluation and inference

---

## Tech Stack

- Python
- TensorFlow / Keras
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
- Jupyter Notebook

---

## Project Workflow

1. Load Medium Articles Dataset
2. Clean and preprocess text
3. Tokenize text
4. Generate n-gram sequences
5. Pad input sequences
6. Train LSTM model
7. Predict the next word from user input
